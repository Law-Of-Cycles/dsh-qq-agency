# 📋 开源发布速查清单 (Release Checklist)

在将本仓库推送到 GitHub 开源或发布至 npm 前，可以快速过一遍本清单：

---

## 一、个性化占位信息替换

| 文件位置 | 待替换项 | 说明 |
| :--- | :--- | :--- |
| `package.json` | `<your-username>` | 替换为你自己的 GitHub 用户名 / 组织名 |
| `README.md` | `<你的用户名>` | 替换为你自己的 GitHub 用户名 / 组织名 |
| `LICENSE` | `Copyright (c) 2026` | 可追加你的昵称或开发者名称 |

---

## 二、本地快速验证

执行以下命令确保全套单元测试与契约测试 100% 绿灯：

```bash
# 运行完整自动化测试套件（92 项）
npm test

# 检查 npm 发布包文件清单（确认无冗余垃圾文件）
npm pack --dry-run
```

若有手机或模拟器连接，可额外执行真机硬件动作走查：
```bash
npm run test:phone
```

---

## 三、三步推送到 GitHub

在 `E:\Desktop\dsh-qq-agency` 目录下直接执行：

```bash
git add .
git commit -m "feat: 初次发布 dsh-qq-agency - 具身玩手机与自主心智QQ伴侣AI"
git branch -M main
git remote add origin https://github.com/<你的用户名>/dsh-qq-agency.git
git push -u origin main
```

---

## 四、可选：发布至 npm

若希望用户能通过 `npm install dsh-qq-agency` 直接安装：

```bash
npm login
npm publish --access public
```
