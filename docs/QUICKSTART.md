# 🚀 零到一保姆级搭建与配对指南 (Quick Start Guide)

本教程带你从零开始，在 5~10 分钟内将 `dsh-qq-agency` 部署到你的 DSH 环境中，并成功连接一台安卓手机或模拟器。

---

## 准备清单

在开始之前，请确认你已准备好：
1. **Node.js**: `>= 20.0.0`
2. **DSH (DeepSeek Harness)**: 0.1.7 或更新版本
3. **QQ 协议端**: 支持 OneBot 11 HTTP 规范（如 NapCat、SnowLuma、Lagrange 等，默认监听 `http://127.0.0.1:3000`）
4. **安卓设备**: 电脑上安装了 MuMu 模拟器 12（推荐），或一台开启了 USB 调试的真实安卓手机

---

## 第一步：连接手机或模拟器

### 方案 A：使用 MuMu 模拟器 12（最推荐，免接线）
1. 启动 MuMu 模拟器 12；
2. MuMu 12 默认开启 ADB 调试，端口通常为 `127.0.0.1:16384`；
3. 打开电脑终端执行：
   ```bash
   adb connect 127.0.0.1:16384
   adb devices
   ```
   看到 `127.0.0.1:16384 device` 即表示连接成功。

### 方案 B：使用真机 USB 连接
1. 进入手机「设置 → 关于手机」，连续点击「版本号」5~7 次开启开发者选项；
2. 进入「设置 → 开发者选项」，开启 **USB 调试**；
3. 用数据线将手机连接至电脑，手机屏幕弹出授权弹窗时，勾选「始终允许此计算机」并点击确定；
4. 终端执行 `adb devices`，确认状态为 `device`。

---

## 第二步：运行真机硬件体检

进入插件目录，执行：

```bash
npm run test:phone
```

脚本会自动检测系统 ADB 环境，并依次执行：
1. 探测电量、亮屏、前台应用与屏幕分辨率；
2. 截取一张真实屏幕截图并保存至临时目录；
3. 抓取当前屏幕 UI 层次语义树（XML）；
4. 打开系统设置并根据文字精准模拟点击；
5. 测试物理 Home 键与返回键。

只要终端最后输出 `✓ 全过 —— 这台机器可以交给她当身体了`，即可放心进入下一步。

---

## 第三步：安装中文输入法（若需打字交互）

原生 ADB 的 `input text` 仅支持标准 ASCII 字符（无法直接输入中文字符）。  
如果你希望 AI 能够在搜索框中键入中文商品名或文字：
1. 下载并安装 [ADBKeyboard.apk](https://github.com/senzhk/ADBKeyBoard/releases) 到你的手机/模拟器中；
2. 在手机系统设置中，将当前默认输入法切换为 **ADB Keyboard**；
3. `dsh-qq-agency` 会在运行时自动检测并启用 Base64 广播输入通道，原生支持各种中文输入。

---

## 第四步：在 DSH 中启用并配置插件

1. **添加插件**：
   ```bash
   dsh plugin --profile desktop add github:Law-Of-Cycles/dsh-qq-agency
   ```
2. **重启 DSH**；
3. 打开 DSH 界面，点击左侧菜单进入 **设置 → 它自己 (dsh-qq-agency)**：
   - **总开关**：开启
   - **试运行**：初次配置建议先开启（只记录想做什么，不向群里真实发消息）；确认无误后再关闭进入全自动模式
   - **目标会话**：选择用于承载伴侣灵魂人设的 Session 会话
   - **主人 QQ**：填入你自己的 QQ 账号
   - **常驻群聊**：勾选你希望她活跃的 QQ 群
   - **允许玩手机**：开启，设备序列号若只有单台可直接留空
   - **允许办事**：按需开启，并设置合理的单笔预算上限（如 50~100 元）
4. 点击右下角 **保存配置**。

至此，全部配置完成！你的伴侣已经开始自主呼吸，并在想念你的时候敲响你的私聊窗口。
